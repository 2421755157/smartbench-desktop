# 智控工作台

Windows 本地桌面工具，单个 exe 离线运行，包含三个可切换模块：文本转语音、通讯调试、U 盘批量下发。

- **技术栈**：.NET 8 + WPF，`net8.0-windows`，无服务端、无数据库、无联网依赖。
- **运行权限**：普通用户权限，不需要管理员。格式化等敏感操作均需手动确认。

---

## 文本转语音

- 调用本机已安装的 SAPI 语音，可切换音色、语速、音高、音量，实时显示输出电平（dBFS）。
- 可导入 TXT，提供常用播报场景的快速预设。
- 导出 MP3 或 WAV。默认 96 kbps 单声道 MP3，通过 Windows Media Foundation 编码。
- dBFS 表示软件输出电平，**不等于**扬声器实际声压（dB SPL）。

## 通讯调试

| 子模块 | 能力 |
| --- | --- |
| RS232 串口 | 文本 / HEX 收发，UTF-8 / GBK / ASCII 编码，CR、LF、CRLF 结尾可选 |
| Modbus RTU | FC03、FC04、FC06、FC16；循环轮询、异常码处理、CRC16 校验 |
| UDP | 本地端口绑定，可选广播发送 |

**界面布局**

- 参数区横贯整行，每项为「标签在上、控件在下」，连接按钮靠右对齐。窗口变窄时参数自动折行，不再出现控件挤在左侧、右侧大片留白的情况。
- 左侧为发送区（可输入、可循环发送），右侧为收发日志，两栏随窗口等比伸缩，底部对齐。
- 发送按钮与收发字节统计并排显示，不再孤立在底部；统计随实际收发字节实时更新。
- Modbus 页签分「串口参数」「协议参数」两行，寄存器数据窗口与帧日志左右分栏。寄存器表格列宽经过收敛，表头不会被截断。
- 深色日志框统一为同一套样式，文字使用等宽字体，HEX 与文本对照输出。

Modbus 采用工业调试常见的 **0 基协议地址**，同时显示设备参考地址，避免把 `40001` / `30001` 直接当报文地址发送：

| 功能 | 协议地址 | 设备参考地址 |
| --- | --- | --- |
| FC03 保持寄存器 | `0` | `HR40001` |
| FC04 输入寄存器 | `0` | `IR30001` |

寄存器表保留最后一次有效值，可编辑别名；选中 FC03 的单行数据后可用 FC06 写回。轮询与手动操作共用同一事务队列，同一 COM 端口不会被 RS232 与 Modbus 同时占用。

寄存器数值可直接编辑，支持十进制与 `0x` 前缀的十六进制（如 `0x1A`）。**只有显式写 `0x` 才按十六进制解析**，因此把字母打错（如 `abc`）会被判为非法输入而不是静默转成 `0xABC` 写进设备；输入非法时单元格标红并提示原因。

所有输入项都会校验范围（从站 1–247、协议地址 0–65535、数量 1–125、写入值 0–65535、端口 1–65535），越界时给出中文提示而不是抛出异常。

**稳定性保护**

- 循环读取连续失败 **10 次**后自动停止并提示，不会因设备掉线而无限刷屏。
- 收发日志先在内存缓冲、再按 200 毫秒批量刷新界面。Modbus 以 100 毫秒周期轮询时也不会把界面消息队列打爆。
- 日志超过 48 000 字符后按整行截断，不会切在字符中间产生乱码。

## U 盘批量下发

**设备识别**

- 最多同时管理 **10 个**可移动设备，插拔自动刷新（3 秒轮询）。
- 列表显示盘符、设备名称、状态、可用空间，每行带独立「格式化」按钮。
- 「全选」「清空选择」用于批量挑选目标；开始复制前会再次核验每个设备的卷序列与剩余空间，拔插或盘符复用过的设备会被跳过。
- 设备列表按行增量更新，不整表重建。**勾选状态与滚动位置在 3 秒轮询中保持稳定**，不会被后台刷新打断；盘符被新设备复用时，该行的勾选状态会自动清除，不会误写到别的盘上。

**同名文件处理**

- 目标盘已有**同名文件时直接覆盖**，不再跳过，也不会生成改名副本。
- 目标盘已有**同名文件夹时合并写入**，其中的同名文件同样被覆盖，文件夹内其他文件保持不动。
- 唯一的例外：目标位置上是个**同名文件夹**、而源是文件。文件夹无法用文件覆盖，这种情况会跳过该项并在结果里列出。
- 覆盖采用「先写临时文件 → 原子替换」：写入过程中断电、拔盘或取消，目标上原来的文件仍然完好，不会变成半截损坏文件；临时文件会被清理。
- 覆盖时旧文件与新文件会在替换瞬间同时占用空间，因此单盘所需空间比净增量略高。若剩余空间提示不足，请先清理目标盘。

**批量格式化**
- 「批量格式化」对勾选设备并行执行快速格式化，各设备之间错峰 400 毫秒启动。
- 文件系统规则：容量 **≤ 32 GB 用 FAT32**，**> 32 GB 用 exFAT**；容量读不到时回退 FAT32（不会误判成大容量盘）。
- 容量探测有三级回退：`DriveInfo` → `Win32_LogicalDisk.Size` → `Win32_DiskDrive.Size`，所以刚插入、尚未被资源管理器挂载的盘也能判断正确。
- 「插入需格式化 U 盘时自动格式化」开关会记忆保存。开启后，插入无法读取的 U 盘会自动快速格式化，失败最多重试 3 次（计数而非一次性拉黑，因此 6 盘、10 盘同插也能逐个格式化成功）。
- 计数在设备拔出后自动清除，**重新插入的 U 盘会重新获得完整重试次数**，不会因为之前失败过就永久跳过。
- 格式化会产生数据丢失，勾选前请自行确认。

**文件与下发**

- 「添加文件」「选择文件夹」或直接把文件 / 文件夹拖进窗口。
- 扫描大目录期间可以继续拖入其他内容，**后续内容会排队合并处理，不会被丢弃**。
- 文件清单为单表勾选式（勾选 / 文件路径 / 大小），支持「全选 / 反选」「移除选中」「清空内容」。
- 支持任意文件格式。文件夹按原名称和层级复制到 U 盘根目录，单文件直接复制到根目录，不额外套上级目录、不自动改名。
- **多盘并行下发**：勾选的 N 个设备同时开始复制（`Task.WhenAll`），进度按总字节数汇总，不是逐盘串行。10 个盘同时写会共享 USB 带宽，整体耗时受最慢的那个盘限制。
- 写入采用 128 KB 缓冲 + 临时 `.partial` 文件，全部写完并 `Flush(flushToDisk: true)` 落盘后才改名为正式文件；中途失败不会留下半个文件。目标路径做了穿越校验，压缩包内的 `..` 无法写出 U 盘目录。
- 单盘失败不影响其他盘，失败原因会汇总到任务状态栏。

**进度显示**

- 任务进度区显示已用时间，以及按当前速率估算的剩余时间（格式化按每台平均耗时估算，下发按已复制字节速率估算）。
- 任务结束（成功、部分失败、取消）后进度条归零并复位状态文字，不会停留在 100% 造成"卡住"的错觉。
- 进度由后台线程只写原子计数、界面按 200 毫秒统一刷新。原先每复制 128 KB 就往界面线程投递一次，10 盘并行复制大文件时会产生上万次投递并导致界面卡死。

**任务日志**

- 任务进度区下方为任务日志，记录每一步操作与结果，可用于产线留痕。
- 每条记录包含时间、级别（信息 / 成功 / 警告 / 失败）与详细信息，逐设备记录复制字节数、耗时、覆盖数量，失败时记录具体原因。
- 记录的节点包括：
  - **程序启动**（含版本号，打开软件即有第一条日志）
  - **检测到 U 盘 / U 盘已移除 / U 盘不可读取 / 重新就绪**（插拔与状态变化实时记录，同一盘符换设备也会分别记录断开与接入）
  - 开始批量下发、每个设备下发完成或失败、覆盖同名文件数量、与同名文件夹冲突而跳过的项、任务汇总
  - 取消与异常终止、批量格式化每台结果、载入与移除文件
- **日志面板默认展开**，占据约 110～160px 高度（随窗口高度按比例伸缩），可直接看到最近 3～6 条记录；内容超出时面板内部滚动。执行下发或格式化时会再次确保面板处于展开状态。
- 标题栏右侧可「导出」为文本文件或「清空」；任务区上边缘有分隔条，**可上下拖动调整日志区高度**。
- 设备表、文件表、任务日志三块按 1 : 1.2 : 1.15 的比例分配窗口高度，中间各有一条可拖动的分隔条。三块在任何窗口尺寸下都同时可见，各自内部独立滚动：
  - **设备表**按约 2～3 行起算，设备多时表格内部滚动并显示滚动条
  - **文件表**同理，文件上百个时在框内滚动，不影响其他区块
  - 拖动任意分隔条可把空间分给更关心的那一块
- 文件区在未添加文件时显示空状态提示，而不是一片空白。

## 运行

需要 .NET 8 SDK：

```powershell
dotnet run --project .\SmartBench.csproj
```

## 发布便携版

生成单文件、自包含、压缩的 exe，目标机器无需安装 .NET 运行时：

```powershell
dotnet publish .\SmartBench.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true `
  -o .\publish\win-x64
```

产物为 `publish\win-x64\智控工作台.exe`（约 70 MB），直接拷给他人双击即可运行。

## 配置存储

以下设置保存在：

```
%LOCALAPPDATA%\SmartBench\settings.json
```

- 「插入需格式化 U 盘时自动格式化」开关。
- 通讯参数：串口与 Modbus 的端口、波特率、数据位、校验位、停止位、编码、行结尾、从站地址、功能码、协议地址、轮询周期、响应超时，以及 UDP 的本地端口、绑定地址、目标主机与端口、广播开关。

通讯参数在打开串口、启动 UDP、切换功能码以及关闭程序时自动保存，下次启动直接恢复。文件为 UTF-8 BOM 编码，用记事本或 PowerShell 打开均为可读中文。

删除该文件即可恢复默认。

## 异常与日志

程序对未捕获异常做了全局兜底：界面线程异常会弹窗提示并写日志，不会直接闪退退出；后台线程与未观察到的任务异常同样记录。日志文件：

```
%LOCALAPPDATA%\SmartBench\crash.log
```

现场出现问题时，把这个文件连同现象描述一起提供即可定位。

## 安全边界

- 本软件不做分区、不做坏道修复，也不会向未挂载的设备写入数据。
- 单盘「格式化」调用 Windows 系统格式化对话框，格式化前有二次确认。
- Windows 自身弹出的"需要格式化"提示来自资源管理器，普通用户态程序无法安全屏蔽；这类设备在软件中被标记为不可读，只有开启自动格式化后才会被本软件接管处理。
- 批量格式化与自动格式化会清空整个 U 盘，操作不可撤销。
- Modbus 写入会改变设备寄存器，仅在确认从站、地址和数值后使用；广播地址 `0` 已在界面中禁用。
- U 盘安全弹出请在 Windows 文件资源管理器或系统托盘中执行，本软件不提供弹出功能。
