# 智控工作台

Windows 本地桌面工具原型，提供三个可切换模块。

- **文本转语音**：使用本机已安装语音，支持音色、语速、音高、音量与 dBFS 显示；可导入 TXT、使用快速预设，并导出 MP3 或 WAV。默认导出为 96 kbps 单声道 MP3。
- **通信调试**：RS232 支持文本/HEX 收发、UTF-8/GBK/ASCII 编码与 CR/LF 结尾；Modbus RTU 支持 FC03、FC04、FC06、FC16；UDP 支持本地绑定和可选广播。
- **U 盘批量下发**：最多列出 10 个可移动设备；可拖入任意文件或文件夹，目录以树状逐级显示。所有文件格式均会加入下发清单；文件夹按原名称和层级复制到 U 盘根目录，单文件直接复制到根目录，不额外创建上级目录或自动改名副本。

## Modbus RTU 数据窗口

Modbus 页面采用工业调试常见的 0 基协议地址，并同时显示设备参考地址，避免将 `40001` / `30001` 直接作为报文地址发送。

| 功能 | 协议地址 `0` | 设备参考地址 |
| --- | --- | --- |
| FC03 保持寄存器 | `0` | `HR40001` |
| FC04 输入寄存器 | `0` | `IR30001` |

可配置串口参数、从站地址、功能码、起始协议地址、数量、轮询周期和响应超时。FC03/FC04 支持循环读取；接收端会进行响应分帧、站号/功能码匹配、长度检查、CRC16 校验、超时和常见异常码处理。寄存器表保留最后一次有效值，并可编辑别名；从 FC03 读取的数据可选择单行后以 FC06 写回。

轮询与手动操作共用单一事务队列，同一 COM 端口不会被 RS232 与 Modbus 模块同时打开。

## 运行

开发环境运行：

```powershell
dotnet run --project .\SmartBench.csproj
```

发布后的便携版本从 `publish\win-x64-v0.4\智控工作台.exe` 启动。

## 安全边界

- 软件不会格式化、分区、修复或向未挂载设备写入数据。
- Windows 自身弹出的“需要格式化”窗口不能由本软件安全屏蔽；此类设备会被标记为不可读，不能选作下发目标。
- “dBFS”表示软件输出电平，不等于扬声器实际声压（dB SPL）。
- MP3 导出通过 Windows Media Foundation 完成，面向 Windows 10/11；编码器不可用时可切换为 WAV。
- Modbus 写入会改变设备寄存器，仅应在确认从站、地址和数值后使用；广播地址 `0` 已在界面中禁用。
- U 盘安全弹出仍需在 Windows 文件资源管理器或系统托盘中执行。
- 下发开始前会重新检查 U 盘卷序列和剩余空间；拔插或盘符复用时会跳过该设备。某一设备失败不影响其他已选择设备。
